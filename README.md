# Research Tool

This is a web application designed to help you plan trips, save activities, and calculate costs. It was generated by converting an LLM's HTML output into a fully functional React + TypeScript + Vite application.

## Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Open the app:**
   Navigate to `http://localhost:5173` in your browser.

## Features

- **Dashboard:** View summaries of total activities, cumulative interest, and estimated costs across all your planned destinations.
- **Trip Sheets:** Add and manage activities for specific cities. Track details like category, interest level, pricing, and links to research.
- **Import Center:** Import lists of activities either in JSON format or by pasting CSV text.
- **Export:** Export your entire plan as a CSV file to open in tools like Excel or Google Sheets.

## Built With

- React
- TypeScript
- Vite
